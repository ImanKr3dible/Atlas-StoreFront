ATLAS Privacy Policy

ATLAS is designed around local project work. The commerce system is separate from the local development workflow.

Local project work

ATLAS is designed so supported local AI workflows can run on the customer’s Windows computer. The commerce service is not intended to receive customer source code, project files, prompts, or local model data merely because ATLAS is being used.

Commerce data

The licensing service may store customer identifiers, subscription and entitlement status, hashed license credentials, release-download events, and support information submitted by the customer.

Payments

Payment details are processed by Stripe. ATLAS does not need to store raw payment-card numbers.

License security

Plaintext license keys are intended to be shown to the customer when issued and stored server-side only as cryptographic hashes. Protected release downloads may use short-lived signed URLs.

Support

If a customer contacts support, ATLAS may store the submitted email address, subject, message, optional license prefix, and ticket status so the request can be handled.

Final production review

Retention periods, deletion procedures, regional privacy rights, production contact details, and any legally required disclosures will be finalized before live sales.
